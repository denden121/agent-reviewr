Прогони задачу через линейный пайплайн из трёх субагентов. Ровно один проход, без возвратов назад.

**Задача:** $ARGUMENTS

## Шаги

1. **Writer.** Вызови субагента `writer` (Agent tool, `subagent_type: "writer"`, `run_in_background: false`). Передай ему текст задачи целиком.
2. **Tests.** Дождись Writer'а и вызови субагента `tester`. Передай ему: текст задачи + отчёт Writer'а (список изменённых файлов и его заметки).
3. **Reviewer.** Дождись Tester'а и вызови субагента `reviewer`. Передай ему: текст задачи + отчёт Writer'а + отчёт Tester'а.

Шаги строго последовательны — каждый следующий агент видит результат предыдущего. Сам код между шагами не правь: твоя роль здесь — только передавать контекст.

## Результат

Не пересказывай отчёты целиком. Выведи сводку:

```
ЗАДАЧА: <одной строкой>
WRITER: <изменённые файлы>
TESTS: <PASS|FAIL>, <N passed / M failed>
REVIEW: <APPROVE|CHANGES_REQUESTED>
БЛОКЕРЫ: <список или «нет»>
```

Затем одним абзацем: готово ли это к использованию как есть. Если тесты красные или ревью вернуло `CHANGES_REQUESTED` — так и скажи прямо и покажи блокеры. Ничего не чини сам: смысл этого варианта в том, что он делает один проход и честно показывает, что получилось. Для доведения до зелёного есть `/flow-loop`.
